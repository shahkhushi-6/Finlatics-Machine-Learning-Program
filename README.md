# Predictive Analytics using Machine Learning

> Finlatics Machine Learning Program (May 2025 – July 2025)

This repository contains projects completed during the Finlatics Machine Learning Program, focusing on predictive analytics and data-driven decision making using machine learning techniques.

## Overview

The objective of this program was to develop machine learning models capable of estimating sales and product quality from input features while deriving actionable insights from real-world datasets.

Throughout the program, various supervised and unsupervised learning techniques were implemented to solve practical business problems.

## Key Highlights

- Developed predictive machine learning models for sales and product quality estimation.
- Performed data preprocessing and feature engineering on real-world datasets.
- Conducted feature correlation analysis to identify significant variables.
- Applied clustering techniques for pattern discovery and customer segmentation.
- Generated insights to support data-driven decision making.

## Machine Learning Techniques

### Supervised Learning
- Linear Regression
- Decision Trees
- Random Forests

### Unsupervised Learning
- K-Means Clustering
